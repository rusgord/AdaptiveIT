# 🎓 AdaptiveIT — Платформа адаптивного тестування

> **Дипломний проєкт** > **Автор:** Гордеюк Р.О.  

**AdaptiveIT** — це сучасний вебзастосунок для створення, проведення та автоматизованої перевірки тестів (опитувань та іспитів). Головна інновація платформи — механізм **адаптивної складності**. 

Система динамічно підлаштовується під рівень знань студента: при правильній відповіді пропонується складніше запитання, при помилці — простіше. Це дозволяє максимально точно та об'єктивно оцінити реальний рівень компетенцій здобувача освіти.

## ✨ Ключові можливості

Платформа підтримує три рівні доступу (ролі), кожна з яких має свій функціонал:

### 👨‍🎓 Для студента
* **Проходження тестів:** Покрокова подача запитань із підтримкою таймера та обмеженням кількості спроб.
* **Адаптивний режим:** Інтелектуальний підбір складності запитань у реальному часі.
* **Різноманіття форматів:** Підтримка одиночного/множинного вибору, зіставлення, впорядкування, текстових відповідей та графічних drag-and-drop завдань.
* **Зручність:** Відновлення незавершених спроб, перегляд історії тестувань та детальних результатів.
* **Соціалізація:** Вступ до навчальних груп за інвайт-кодами.

### 👨‍🏫 Для викладача / Адміністратора
* **Конструктор тестів:** Гнучке налаштування параметрів (ліміти часу, вікно доступності за датами, перемішування запитань/відповідей, кількість запитань на одну спробу).
* **Створення запитань:** Вбудований редактор запитань із підтримкою завантаження зображень та налаштування графічних зон для візуальних тестів (drag-and-drop).
* **Управління доступом:** Призначення тестів для всіх, для конкретних навчальних груп, за списком студентів або за унікальним кодом доступу.
* **Перевірка та аналітика:** Перегляд статистики спроб, формування рейтингів та зручна черга для ручної перевірки розгорнутих відповідей (із виставленням балів та коментарями).
* **Управління групами:** Створення груп, генерація інвайт-кодів, управління складом учасників.

## 🛠 Технологичний стек

Проєкт побудовано за класичним патерном **MVC (Model-View-Controller)**.

| Шар / Компонент | Технологія |
|------------------|------------|
| **Платформа** | ASP.NET Core MVC (.NET 8/7), C# |
| **База даних** | MySQL |
| **ORM** | Entity Framework Core (через `Pomelo.EntityFrameworkCore.MySql`) |
| **Аутентифікація** | ASP.NET Core Identity (Рольова модель, скидання пароля, e-mail) |
| **Frontend / UI** | Razor Pages (`.cshtml`), HTML5, CSS3, JavaScript |
| **Обробка графіки** | SixLabors.ImageSharp (стиснення та ресайз зображень) |
| **Поштовий сервіс** | SMTP (System.Net.Mail) |

## 🧠 Як працює адаптивний алгоритм?

Якщо в налаштуваннях тесту увімкнено прапорець `IsAdaptive`, алгоритм починає керувати подачею запитань (у діапазоні складності від 1 до 10):
1. Після кожної відповіді система аналізує її правильність.
2. Цільова складність наступного запитання = *складність попереднього ± 1*.
3. З пулу запитань, що залишилися, обирається те, складність якого максимально наближена до цільової.
4. У неадаптивному режимі запитання подаються згідно з базовими налаштуваннями (по порядку або перемішуються).

Автоматична перевірка балів враховує часткові відповіді (наприклад, штрафи за зайві позначки у `MultipleChoice` або пропорційні бали за `TextMatch`/`Ordering`). Розгорнуті відповіді (`LongAnswer`) автоматично відправляються в чергу на ручну перевірку викладачем.
